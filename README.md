# Сервис генерации комиксов на основе ИИ Kandinsky & GigaChat  
# Запуск проекта

## Запуск фронтенда из папки проекта:

- `npm run frontend:i` - требуется при первом запуске, чтобы установить пакеты (у вас должен быть установлен npm и node 20 версии);
- `npm run frontend:dev` - запуск фронта на <http://localhost:3000/>

## Запуск бэкенда из папки ./packages/backend

### Действия при первом запуске (команды для Git Bash):

- `python -m venv venv` - создание виртуального окружения (предпочтительная версия python 3.12);
- `source venv/scripts/activate` - активация виртуального окружения;
- `pip install -r requirements.txt` - установка зависимостей

### Запуск базы данных (требуется предварительно установленный и запущенный Docker Desktop):

- `docker-compose up -d`

### Запуск сервера:

- `python main.py` - развертывание сервера, документация Swagger доступна по ссылке <http://localhost:8000/docs>
